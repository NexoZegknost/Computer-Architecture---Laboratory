\subsection{Exercise 4}
\task{Requirement}
Write a MIPS program to take a non-negative integer from the user (you
need to check if the user input the correct number). Print the factorial
number of that integer into the terminal.\\
For example, if the user input \textbf{5}, the output should be \textbf{120}. If the user
input \textbf{-2}, the output should be \textbf{A factorial for your number can not be
found.}

\task{Test cases}
\testcase{4}{1}{\texttt{5}}{\texttt{120}}
\testcase{4}{2}{\texttt{0}}{\texttt{1}}
\testcase{4}{3}{\texttt{-2}}{\texttt{A factorial for your number can not be found.}}

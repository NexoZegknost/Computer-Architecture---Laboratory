\section{Introduction}
\begin{itemize}[itemsep=6pt]
  \item This report presents the solutions for Lab \LabNumber{} -- \textit{\LabTitle}.
  \item All programs are written in MIPS assembly and tested on the MARS MIPS simulator.
  \item The programs use conditional branch and unconditional jump instructions,
        and call procedures. Exercises 2 and 4 are solved with recursive procedures.
  \item Each exercise is verified with three test cases. For every test case, the input,
        the expected output and a screenshot of the actual run are given.
\end{itemize}

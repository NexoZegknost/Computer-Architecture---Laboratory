\task{Requirement}
Cho bộ nhớ chính tổng dung lượng là 256MB, bộ nhớ cache có kích thước là 256KB, 1 block 64 words, đơn vị truy xuất của hệ thống là 2 byte.
Xác định tag, index, half-word offset với cấu hình cache sau:
\begin{enumerate}[label=(\alph*), itemsep=0pt]
  \item Direct mapped
  \item 4-way set associative
  \item Fully associative
\end{enumerate}

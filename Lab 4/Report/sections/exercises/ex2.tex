\subsection{Exercise 2}
\task{Requirement}
The main memory has a total size of 256MB, the cache size is 256KB, one block is
64 words and the access unit of the system is 2 bytes. Determine the tag, index
and half-word offset for the following cache configurations:
(a) Direct mapped, (b) 4-way set associative, (c) Fully associative.

\task{Solution}
\begin{itemize}[itemsep=2pt]
  \item Number of addressable half-words: $256\text{MB}/2\text{B} = 2^{28}/2^{1} = 2^{27}$
        $\Rightarrow$ address width is 27 bits.
  \item Block size: $64 \times 4\text{B} = 256\text{B} = 128$ half-words $= 2^{7}$
        $\Rightarrow$ half-word offset is 7 bits.
  \item Number of blocks in cache: $256\text{KB}/256\text{B} = 2^{18}/2^{8} = 2^{10}$ blocks.
  \item Tag $= 27 - \text{Index} - \text{Offset}$.
\end{itemize}

\subsection{Exercise 4}
\task{Requirement}
Write a MIPS program to print out the 4-bit binary value of a decimal
number. The number should be selected by the user.\\
The input shall be restricted only to a positive integer that is less than 16.\\
The input prompt should be: ``Please enter a positive integer less than 16: ''.\\
For example, if the decimal number is \textbf{10} then the output should be \textbf{Its
binary form is: 1010}.

\task{Test cases}
\testcase{4}{1}{\texttt{10}}{\texttt{Its binary form is: 1010}}
\testcase{4}{2}{\texttt{5}}{\texttt{Its binary form is: 0101}}
\testcase{4}{3}{\texttt{15}}{\texttt{Its binary form is: 1111}}

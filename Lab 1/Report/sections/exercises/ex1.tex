\subsection{Exercise 1}
\task{Requirement}
Write a MIPS program that takes a name as a string and print out a
``Hello $<$name$>$!''.\\
For example, if the input is \textbf{John}, then the output should be \textbf{Hello, John!}.

\task{Test cases}
\testcase{1}{1}{\texttt{John}}{\texttt{Hello, John!}}
\testcase{1}{2}{\texttt{Duc}}{\texttt{Hello, Duc!}}
\testcase{1}{3}{\texttt{Nguyen Huynh Huu Duc}}{\texttt{Hello, Nguyen Huynh Huu Duc!}}

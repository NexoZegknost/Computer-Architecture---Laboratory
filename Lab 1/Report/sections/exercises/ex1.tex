\subsection{Exercise 1}
\task{Requirement}
Write a MIPS program that takes a name as a string and print out a
``Hello $<$name$>$!''. For example, if the input is \textbf{John},
then the output should be \textbf{Hello, John!}.
The exclamation mark must be on the same line as ``Hello, $<$name$>$''.

\task{Test cases}
\testcase{1}{1}{\texttt{John}}{\texttt{Hello, John!}}
\testcase{1}{2}{\texttt{Nguyen Van An}}{\texttt{Hello, Nguyen Van An!}}
\testcase{1}{3}{\texttt{Lan}}{\texttt{Hello, Lan!}}

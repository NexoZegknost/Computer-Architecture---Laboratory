\subsection{Exercise 2}
\task{Requirement}
Write a MIPS program to allow the user to first input an array with 5
elements. The prompts should be: ``Please input element 0:'', ``Please input
element 1:'', etc. Then print the value from the element chosen by the user
(Assume the user only input 0 to 4). The prompt for this is: ``Please enter
index:''.

For example, an array may have elements such as \textbf{5, 10, 15, 20, 25}. If
the user input \textbf{1} the output shown on the terminal should be 10. If the user
input \textbf{4}, the output should be \textbf{25}.

\task{Test cases}
\testcase{2}{1}{elements \texttt{5, 10, 15, 20, 25}; index \texttt{1}}{\texttt{10}}
\testcase{2}{2}{elements \texttt{5, 10, 15, 20, 25}; index \texttt{4}}{\texttt{25}}
\testcase{2}{3}{elements \texttt{-7, 3, 0, 42, -100}; index \texttt{4}}{\texttt{-100}}
